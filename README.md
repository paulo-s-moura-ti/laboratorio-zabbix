# Laboratório Zabbix

## 📌 Sobre o projeto

Projeto prático desenvolvido para estudar e aplicar conceitos de
monitoramento de infraestrutura utilizando Zabbix.

## 🎯 Objetivos

- Implementar um servidor de monitoramento
- Monitorar servidores e máquinas
- Trabalhar com Zabbix Agent
- Praticar monitoramento via SNMP
- Criar dashboards e triggers
- Aprender diagnóstico e resolução de problemas

## 🛠️ Tecnologias utilizadas

- Ubuntu Server
- Zabbix
- MySQL
- Apache
- PHP
- Zabbix Agent
- SNMP

## 🖥️ Ambiente

Servidor Zabbix executado em ambiente virtualizado utilizando
Ubuntu Server.

## 📊 Monitoramento

- Ubuntu Server
- Windows
- Equipamentos de rede
- CPU
- Memória
- Armazenamento
- Disponibilidade
- Serviços
- Alertas e problemas

## 🔧 Troubleshooting

Durante a implementação foram realizados testes e correções
de problemas relacionados à instalação, serviços, banco de dados,
agentes e comunicação entre os hosts.

## 📚 O que aprendi

- Administração básica de servidores Linux
- Gerenciamento de serviços com systemd
- Configuração de servidores
- Monitoramento de infraestrutura
- Zabbix Agent
- SNMP
- Diagnóstico de problemas
- Criação de dashboards e triggers
